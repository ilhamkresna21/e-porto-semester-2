Kelola E-Portofolio

Masuk dengan token GitHub untuk mengubah foto, teks, dan link Google Drive. Token hanya disimpan di browser ini dan tidak pernah dikirim ke mana pun selain GitHub.

Cara membuat token GitHub (sekali saja)
  1. Buka github.com/settings/tokens.
  2. Klik Generate new token → Fine-grained token.
  3. Nama: E-Portofolio Admin. Expiration: 90 hari.
  4. Repository access: Only select repositories → pilih e-porto-semester-2.
  5. Permissions → Contents: Read and write.
  6. Generate token, salin, lalu tempel di kolom di atas.

Alternatif token classic: buka github.com/settings/tokens, pilih Generate new token (classic), centang public_repo.

Penting: gunakan admin hanya di komputer pribadi. Setelah selesai, klik Hapus token di kanan atas.
